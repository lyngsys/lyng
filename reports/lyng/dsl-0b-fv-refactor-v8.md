# Lyng JS V8 v7 Benchmark Report — DSL-0b FV Refactor (B19)

Evidence for DSL-0b Batch 3 (Tasks B14–B19): the FeedbackVector
flat-array refactor. The α dispatch path is still active (DSL is wired
end-to-end at the type level, but no asm trampoline runs yet), so this
benchmark measures whether (a) eager flat-array allocation at install
and (b) per-record-site dual-write into the flat storage introduce a
measurable cost vs the legacy `Vec<Option<FeedbackSiteState>>` alone.

## Δ vs `pre-dsl-0-v8-baseline.md`

| Benchmark | Baseline | This run | Δ |
| --- | ---: | ---: | ---: |
| `Richards` | 317 | 318 | +0.3% |
| `DeltaBlue` | 360 | 357 | -0.8% |
| `Crypto` | 256 | 274 | +7.0% |
| `RayTrace` | 417 | 425 | +1.9% |
| `NavierStokes` | 457 | 461 | +0.9% |
| `Splay` | 1342 | 1346 | +0.3% |

All deltas are within the ±5% noise envelope except **Crypto**
(+7.0%). The Crypto baseline sample stream `(256, 273, 255, 274, 256)`
has high run-to-run variance — the bimodal distribution suggests
warmup/feedback-allocation timing jitter rather than a systematic
shift. This run's stream `(273, 274, 273, 275, 276)` is much tighter
and consistent with the upper mode of the baseline; the +7.0% reflects
which mode the median lands on, not a steady-state regression.
DeltaBlue (-0.8%) and Splay (+0.3%) are well within noise.

**Conclusion**: no benchmark regressed > 5%. The dual-write
(`mirror_flat_slot`) cost is invisible at the V8 v7 suite level — it
clones the per-slot `FeedbackSiteState` only on cold IC update paths,
and the hot inline-cache paths (`record_named_property_fast_hit`,
`try_keyed_dense_index_*`) emit one extra clone per slot mutation
which is amortized over the millions of cache hits between updates.

## Raw report

This report is generated by `cargo run --release -p lyng-bench -- v8suite`.

Each benchmark runs in an isolated `lyng --shell` subprocess per sample so
warmup, GC, feedback caches, and tier transitions don't leak between samples.
Score = `100 × reference_µs / mean_µs` (V8 standard formula); higher is better.

## Configuration

- Samples per benchmark: `5`
- Per-sample timeout: `120s`
- lyng binary: `target/release/lyng`
- V8 v7 sources: `testdata/js-benchmarks/v8-v7`
