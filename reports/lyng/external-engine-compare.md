# Lyng JS External Engine Comparison

This report is generated by `cargo run --release -p lyng-bench -- compare --report reports/lyng/external-engine-compare.md`.
It runs the same standalone JavaScript workload files through Lyng JS, QuickJS, and JSC (LLInt-only, `--useJIT=false`).

## Settings

- Report: `reports/lyng/external-engine-compare.md`
- JSON: `reports/lyng/external-engine-compare.json`
- Scripts dir: `/tmp/lyng-bench-compare-scripts`
- Corpus: `v8-v7`
- Full suite: `false`
- Samples: `3`
- Warmup samples: `1`
- Loop trips: `2048`
- Timeout: `60000ms`

## Comparison Policy

- QuickJS is the primary interpreter baseline.
- JSC LLInt (`--useJIT=false`) is the WebKit interpreter reference — no Baseline/DFG/FTL tiers, comparable shape to a polymorphic-IC-driven interpreter.
- Treat parity as a workload-family measurement, not exact equality across every script.
- QuickJS score ratio is `quickjs score / engine score`; lower is better, and QuickJS is `1.00x`.
